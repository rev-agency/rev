# R.E.V. — Events & Experiences

Многостраничный статический сайт в стиле предоставленного moodboard.

## Структура
- `index.html` — главная
- `services.html` — услуги
- `projects.html` — проекты / галерея
- `about.html` — о бренде и ценностях
- `contact.html` — заявка
- `styles.css` — общий дизайн
- `script.js` — анимации, переходы, меню, слайдер и форма
- `assets/` — подготовленные изображения из предоставленного референса

## Перед публикацией
1. Почта обратной связи (`rev.event.agency@gmail.com`) уже подставлена на всех страницах и в `script.js`.
2. При необходимости замени тексты-заглушки и изображения в `assets/`.
3. Открой `index.html` через локальный сервер (например, VS Code Live Server), чтобы проверить переходы.

## Форма
Сейчас форма формирует письмо через `mailto:`. Это не серверная отправка. Для полноценной отправки без почтового клиента позже можно подключить Formspree, Netlify Forms или собственный backend.
